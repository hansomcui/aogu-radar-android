# E-tone v0.5（清云）— 加强人声感

主人 2026-10-18 15:10：继续加强人声的特点。

## 改动（相对 v0.4）
1. 提示音「自举」：不再用 Kokoro 原声，改用 v0.4 中质检分最好的三段 ZipVoice 输出（第 4、5、7 短句，约 7.6 s）作提示音，音色和语流更接近自然说话。
2. 按整句合成（v0.4 是按逗号短句），保留句内连贯的语调起伏，减少拼接感；每句 3 候选自动质检。
3. 句间停顿加 ±15% 随机抖动（固定种子 20261018），不再机械等长。
4. 加极轻的小房间早期反射（11/23/37 ms，衰减 0.10/0.06/0.035），去掉过干的合成感。
5. ZipVoice speed 0.88（稳定区间），柔化 EQ 与响度同 v0.4（A 档 ×0.81）。
