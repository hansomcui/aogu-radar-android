# E-tone / F-tone 基础版 v0.2（清云）

来源：主人 2026-10-18 07:42 指示——保留 A、B；A 改为 E-tone 基础版，B 改为 F-tone 基础版。其余档（C、D、旧 E）停止。

## 百分比怎么落到参数上（清云的解释，可再调）
| 要求 | 落实方式 | 实测（对比基础档 run1） |
|---|---|---|
| E 轻 15% | 语音段 RMS = A 实测 RMS × 0.85，并加轻气声 −30 dB | RMS 比 0.84 |
| E 柔 30% | 高频倾斜 +2 dB → −1 dB；音域 ×0.85 | p90/p10 音域比约 0.93（句尾上扬抵消一部分） |
| E 慢 15% | length_scale 1.05 → 1.17，句间停顿 380 → 440 ms | 语速 3.96 → 3.40 字/秒，比 0.86 |
| E 嗲 | 整体音高 +1.0 半音（共 +1.5）、句尾上扬 +2.5 半音、句尾 20% 拉长 1.35 倍 | F0 中位 266.5 → 283 Hz |
| E 台湾腔 | 用词：早安喔、耶、啦、嘛、有睡好吗、一下下、来看看、慢慢讲；句尾拉长上扬 | 只做了用词和句尾韵律；平翘舌不分、轻声少等发音特征未做 |
| F 柔 20% | 高频倾斜 −1.5 → −2.5 dB；音域 ×0.9（0.90 → 0.81） | p90/p10 音域比约 0.93 |
| F 轻 5% | RMS = B 实测 RMS × 0.95 | RMS 比 0.94 |
| F 慢 5% | length_scale 1.12 → 1.13，停顿 520 → 546 ms，句尾拉长 1.1 倍 | 语速比 0.95 |
| F 关中西安话遣词断句 | 用词：今儿个、日头、咧、夜个、额（我）、嫑、给额说、夜黑、咋样、谝、停当、一搭、不言传、么；短句断开 | 普通话读音；关中话声调（如阴平读降调）未做 |

台词：text_E_tw.txt、text_F_xa.txt（内容见源码）。
