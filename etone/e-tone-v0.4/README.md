# E-tone v0.4（清云）— 修复 v0.3 第 12–13 秒骤轻变调

主人 2026-10-18 10:31 反馈：F 不要了；E 极不连贯，12–13 秒声音突然很轻很小、完全变调。

## 原因（已核实）
v0.3 用 ZipVoice speed=0.57 硬放慢，长句（11.7 秒）中段失稳：第 13 秒音量降到 −33.6 dB（前后约 −18 dB），音高同时偏移。

## 修复
1. 放慢改由「提示音」带：Kokoro 用 length_scale 1.35 生成慢速提示音，ZipVoice 以 speed 0.95（接近正常）模仿其语速，不再硬拉伸。
2. 逐短句（按，。？；切）合成，每句 3 个候选，自动打分（句中持续低 12 dB 以上的时长、音高偏离提示音中位、音高跳变、语速异常），取最稳的一个。
3. 各短句响度对齐；后期仅高频 −6 dB、低通 9 kHz、整体响度为 A 档的 0.81。无 PSOLA、无加噪。

## 实测（run3）
- 总长 45.8 s（v0.2 为 39.7 s，v0.3 为 43.1 s）；句内语速 3.30 字/秒（v0.2 3.40）。
- 20 个短句的响度中位在 −19.7 至 −22.8 dB 之间；选中候选最长「句中骤降」0.22 s（v0.3 为数秒级）。
- 各短句音高相对提示音偏离 0.17–1.75 半音。
- 详见 logs/Etone_E_tw4_run3.log.json（含每句全部候选得分）。
