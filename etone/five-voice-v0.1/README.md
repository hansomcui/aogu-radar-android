## 处理流程
1. 台词按句（。？！；）切分，每句用 Kokoro 合成（单线程）。
2. Praat 重合成（PSOLA）：整体音高平移、围绕均值缩放音域、句尾 25% 线性上扬（问句至少 +1 半音）。注：Praat 6.4.27 barren 版对 24 kHz 直接做 Manipulation 会报错，脚本先重采样到 48 kHz 再回 24 kHz。
3. 按档拼接句间停顿（逗号/分号处为 70%）。
4. 轻微高频倾斜、按包络调制的高通噪声模拟气声（固定随机种子 20261018）。
5. 峰值归一到 −1 dBFS，末尾 50 ms 淡出，输出 24 kHz WAV 和 128k MP3。

## 复现
```
# 依赖：见 VERSIONS.txt 中的下载地址与 sha256
python3 src/make_voice.py E --tag run1        # 生成 E 档完整版
python3 src/make_voice.py E --max-seconds 10  # 10 秒片段
python3 src/compare_runs.py                    # 比较 run1/run2
```
修改 src/paths.json 指向本机的 sherpa-onnx、Kokoro、Praat 目录。
